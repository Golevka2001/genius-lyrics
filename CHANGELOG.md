# Changelog

## [Unreleased]

### Added

- Multiple annotations per line, paged with arrows and a counter.
- `Verified`/`Unreviewed` labels, with the author's avatar and name.

### Fixed

- Lyric highlighting no longer runs ahead while audio buffers.
- The active line stays centred as it advances.

### Changed

- Hovering or opening a note lights the whole run it spans.

## [0.1.0] - 2026-10-12

First release of Genius Lyrics for Spicetify.

### Added

- Genius lyrics with annotations attached to the lines they explain.
- Experimental synced lyrics with playback highlighting.
- Caching for lyric and annotation requests.
